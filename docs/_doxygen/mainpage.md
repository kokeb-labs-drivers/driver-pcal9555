# PCAL9555 Driver API reference {#mainpage}

The classes, types and registers of the PCAL9555 driver, generated from the headers in `inc/`.

Start with pcal9555::PCAL9555, the driver, and pcal9555::I2cInterface, the base of the port you write. Errors are
pcal9555::Error inside pcal9555::Result; the configuration is pcal9555::Config.

The guides, with examples that compile, are on the documentation site: <a href="../">PCAL9555 Driver
documentation</a>.
