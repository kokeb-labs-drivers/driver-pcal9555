Detailed Description

Everything EnsureInitialized() and ApplyConfig() write to the chip.

Bit n of each mask is pin n. The defaults are the power-up values of the registers, so Config{} changes nothing on a freshly powered chip. The fields below variant marked "PCAL9555A" must keep their default when variant is Variant::Pca9555 (Validate() returns Unsupported otherwise).
