◆ I2cFailure

enum class pcal9555::I2cFailure : uint8_t
strong

Why a Write() or WriteRead() hook returned false, as the optional GetLastFailure() hook reports it.

Only AddressNack changes what the driver returns: nothing acknowledged the address byte, so nothing is at the address, and the driver returns Error::NoDevice. Every other failure, and every failure of a port without the hook, is Error::Bus.

Enumerator
Other 

Arbitration lost, a stuck line, a timeout, or a NACK the port cannot place.

AddressNack 

No device acknowledged the address byte.

DataNack 

The device acknowledged its address, then did not acknowledge a data byte.

◆ kRepeatedStart

constexpr bool pcal9555::kRepeatedStart = true
inlineconstexpr

true: a register read is a combined write-read with a repeated START (section 7.2): the command byte is written, then the address is sent again with R/W = 1 after a restart.
