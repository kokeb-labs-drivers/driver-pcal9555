Detailed Description

PCAL9555 driver: the one header to include.

Copyright

pcal9555::PCAL9555<Port> drives one NXP PCA9555 or PCAL9555A 16-bit I2C GPIO expander through a platform port you write (see pcal9555_i2c_interface.hpp). The driver has no platform code, allocates nothing, throws nothing, takes no lock and is not thread-safe: give each object one owner, or guard it with one mutex.
