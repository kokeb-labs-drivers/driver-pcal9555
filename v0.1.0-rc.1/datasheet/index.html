Datasheet map¶

The driver follows the NXP PCAL9555A and PCA9555 data sheets. This page says which revisions, where to get them, and where each part of the driver is described in them, so you can check any behaviour against the source. Section names and page numbers are the data sheets' own; the printed page numbers equal the PDF pages.

The PCAL9555A is a superset of the PCA9555 (same pins, address and registers 0x00 to 0x07), and the driver's behaviour is defined by it. Each topic cites the PCAL9555A data sheet; a second row cites the PCA9555 data sheet where the driver also runs on that part and its data sheet has its own section.

  • Datasheet: PCAL9555A Low-voltage 16-bit I2C-bus GPIO with Agile I/O, interrupt and weak pull-up, NXP PCAL9555A, revision Rev. 2 (2014-12-19). Get it from the vendor page or as a PDF. SHA-256 of the file used: 76a60b066b420e86acdd5d01bcd43ef44ca24f2f1eb0e669987f769c315be888.
  • Datasheet: PCA9555 16-bit I2C-bus and SMBus I/O port with interrupt, NXP PCA9555, revision Rev. 10 (2017-11-08). Get it from the vendor page or as a PDF. SHA-256 of the file used: 9f4f9c0ce4c461d71e0a46858394f830c74daba72bb6616f368af78a39f44b1f.

When the data sheets and the driver differ¶

The driver is written against the revisions above. If you have a newer revision, compare its "Revision history" section with the topics above; a change to a register, a power-up value or a bus transaction is a bug report for this repository. Where the driver goes beyond the data sheets (how a PCA9555 answers a PCAL9555A-only command byte, which neither data sheet defines), Hardware and the Contract say so.

The repository never contains the PDFs themselves: vendors own their documents. Download them from NXP, and compare each file's SHA-256 with the one above to confirm you have the same file.
