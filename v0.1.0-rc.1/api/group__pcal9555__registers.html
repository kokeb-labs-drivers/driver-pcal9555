◆ kIdentityPattern

constexpr uint16_t pcal9555::reg::kIdentityPattern = 0x55AA
inlineconstexpr

Written to the polarity inversion pair at start-up and read back before the configuration is written: alternating bits, so that neither a line stuck at 0 or 1 nor a device that acknowledges everything and returns a fixed byte can echo it. Polarity only changes how inputs read.
