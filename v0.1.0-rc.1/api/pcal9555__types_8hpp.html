Detailed Description

Public types of the PCAL9555 driver: errors, Result<T>, pins and configuration.

Copyright
Copyright (c) 2026 The driver-pcal9555 authors. SPDX-License-Identifier: MIT

Everything here is plain data with no platform dependency, so handlers, tests and tools can include it without the driver template. The configuration defaults are the power-up values of the registers (PCAL9555A data sheet Rev. 2, table 4), so Config{} describes a chip that was just powered up.
